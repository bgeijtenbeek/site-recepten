---
title: Spinaziesoep
description: Simpele spinaziesoep met croutons/knapperbolletjes en een broodje er bij.
mealType: Hoofdgerechten
kenmerken: [Vega, Soep]
totalTime: 15
servings: 4
ingredients:
  - { name: melk, quantity: "500", unit: ml }
  - { name: water, quantity: "400", unit: ml}
  - { name: groentenbouillon tabletten, quantity: "2" }
  - { name: diepvries spinazie (gehakt), quantity: "300", unit: g }
  - { name: croutons / knapperbolletjes, quantity: "1", unit: zakje }
  - { name: Stokbrood nog af te bakken (Wit/Bruin), amount: "2-3" }
  - { name: Beleg, amount: "naar wens" }
steps:
  - Verwarm de oven voor op de vereiste temperatuur en bak tijdens het koken ook de broodjes af.
  - Breng de melk met 4 dl water en de 2 bouillonblokjes aan de kook in een pan.
  - Voeg de spinazie toe en laat de groente ontdooien in de hete vloeistof; roer de soep af en toe door.
  - Wanneer alles ontdooid en opgewarmd is kun je de alles nog eens extra fijn mixen/blenderen.
  - Opdienen maar, vergeet niet ook de croutons / knapperbolletjes nog toe te voegen of aan te bieden. Serveer met het stokbrood en beleg. Eet smakelijk!
---
