---
title: Tagliatelle met champignons
description: Romige tagliatelle met champignons, ontbijtspek, lente-ui en Mon Chou.
image: ../../assets/recipes/tagliatelle-met-champignons.jpeg
imageAlt: Een bord tagliatelle met champignons, ontbijtspek en bieslook
mealType: Hoofdgerechten
kenmerken: [Vlees, Pasta]
totalTime: 30
servings: 4
ingredients:
  - { name: tagliatelle (lintmacaroni), quantity: "500", unit: g }
  - { name: zout en peper, amount: naar smaak }
  - { name: champignons, quantity: "500", unit: g }
  - { name: lente-uitjes, quantity: "8" }
  - { name: knoflook, quantity: "2", unit: tenen }
  - { name: boter, quantity: "50", unit: g }
  - { name: "ontbijtspek, in plakjes", quantity: "100", unit: g }
  - { name: slagroom, quantity: "250", unit: ml }
  - { name: Mon Chou, quantity: "200", unit: g }
  - { name: Provençaalse kruiden, quantity: "2", unit: el }
  - { name: olijven, amount: naar smaak }
  - { name: gesnipperde bieslook, quantity: "2", unit: el }
steps:
  - Kook de tagliatelle beetgaar in ruim kokend water met zout. Maak ondertussen de champignons, lente-uitjes en knoflook schoon. Snijd de champignons in vieren, de lente-uitjes in dunne ringen en snipper de knoflook.
  - Verhit de boter in een pan en bak het ontbijtspek knapperig. Voeg de champignons, lente-ui en knoflook toe en bak alles al omscheppend ongeveer 3 minuten. Roer de slagroom erdoor en verkruimel de Mon Chou erboven. Breng op smaak met zout, peper en Provençaalse kruiden en laat de saus ongeveer 5 minuten zachtjes pruttelen. Roer af en toe.
  - Snijd de olijven in vieren. Laat de tagliatelle goed uitlekken en schep deze door de saus. Bestrooi met de olijven en de bieslook.
